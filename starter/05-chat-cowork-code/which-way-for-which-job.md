# Which way for which job

Print it, or keep it open next to Claude. Tested on claude.ai, 16 Oct 2026.

| The job | Way | Why |
|---|---|---|
| A quick question, a rewrite, a check of your text | Chat | One question, one answer |
| Explain a document you paste or upload | Chat | You read the answer and decide |
| Draft an email or a post | Chat | You stay in the loop on every version |
| Turn an export into a spreadsheet with totals | Cowork | A task with steps and a file at the end |
| Read many files and make one summary or report | Cowork | Claude works through the files on its own |
| Tidy a folder: rename, sort, sum up | Cowork | Needs your files: use the desktop app and connect only that folder |
| A change to a website or an app | Code | Software lives in a folder or a GitHub repo |
| Fix and test a script | Code | Claude runs the code and checks its own work |

## Three rules

1. Not sure? Start in Chat.
2. You copy-paste the same thing three times? It is a task: move it to Cowork.
3. The result is software? Use Code.

## Plans

- Chat: every plan.
- Cowork: paid plans (Pro, Max, Team, Enterprise).
- Code: paid plans. On Team and Enterprise, a seat that includes Claude Code.
