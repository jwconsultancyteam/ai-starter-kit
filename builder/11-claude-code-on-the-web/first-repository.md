# Your first repository, with the sample export in it

A repository is a folder on GitHub that keeps every version of its files. Claude Code on the web works in one.

1. Make a free account on github.com, or sign in.
2. Top right, click **+**, then **New repository**.
3. Name: `weekly-shipments`. Choose **Private**. Set **Add README** to **On**. Click **Create repository**.
4. Above the list of files, click **Add file**, then **Upload files**.
5. Drag in [shipments-export-sample.csv](shipments-export-sample.csv). Choose **Commit directly to the main branch**
   and click the green button at the bottom (**Commit changes**).

Done. Go back to [step 11](README.md), "Where", step 2.

Steps from GitHub's own documentation, 23 Oct 2026. If a button has another name, the order stays the same.
