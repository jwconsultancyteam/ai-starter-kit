# Your first repository, with the sample export in it

A repository is a folder on GitHub that keeps every version of its files. Claude Code on the web works in one.

1. Make a free account on github.com, or sign in.
2. Top right, click **+**, then **New repository**.
3. Name: `weekly-shipments`. Choose **Private**. Click **Create repository**.
4. On the empty repository page, click **uploading an existing file**.
5. Drag in [shipments-export-sample.csv](shipments-export-sample.csv). Click **Commit changes**.

Done. Go back to [step 11](README.md), "Where", step 2.
