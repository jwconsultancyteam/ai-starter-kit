# Context pack: [name of the job]

A context pack holds the rules for one job. CLAUDE.md points to it, so it is used only for that job.
Example: [monday-overview.md](monday-overview.md).

Who reads the result: [who, when, how much time they have]

Input: [which file or files]

Output, in this order:
1. [The first line. Make it something you can check, such as "Your first line is the table."]
2. [The main part]
3. [At most N short lines after it, and what they are about]

Done when: [a check anyone can do]

In CLAUDE.md, add one line:
- For the [name of the job], follow [file name].md.
